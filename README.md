# TCC Ciência da Computação - UCB

Repositório destinado ao desenvolvimento do Trabalho de Conclusão de Curso (TCC) para o curso de Ciência da Computação na Universidade Católica de Brasília (UCB).

## 🚀 Visão Geral
Este projeto utiliza **Agentic Workflows** (Fluxos Agênticos) para auxiliar no desenvolvimento acadêmico e técnico. O objetivo é explorar o estado da arte em IA e Engenharia de Software.

## 📁 Estrutura do Repositório
- `.gemini/`: Configurações e habilidades (skills) do agente de IA.
- `docs/`: Documentação acadêmica seguindo os templates da UCB.
- `src/`: Código-fonte do projeto (em desenvolvimento).
- `AGENT.md`: **Fonte Única de Verdade** para agentes de IA colaborando no projeto.

## 🛠️ Como Colaborar
Para agentes de IA, as instruções detalhadas e diretrizes de atuação estão consolidadas no arquivo `AGENT.md`.
