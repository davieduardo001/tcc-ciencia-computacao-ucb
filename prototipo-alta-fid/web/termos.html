Termos e Privacidade

Última atualização: junho de 2026 · Em conformidade com a LGPD (Lei nº 13.709/2018).

1. Aceitação dos termos

Ao criar uma conta no Movecity, você concorda com estes Termos de Uso. O Movecity é um projeto-piloto acadêmico (TCC — UCB) de mobilidade urbana colaborativa para o Distrito Federal.

2. Natureza das informações

Os dados de localização de ônibus são fornecidos pela API oficial do GDF (SEMOB) e combinados com reportes colaborativos. As estimativas de horário são aproximadas e não garantem a operação efetiva das linhas.

3. Reportes colaborativos

O usuário compromete-se a enviar reportes verídicos. Ocorrências são validadas por cruzamento (mínimo de 2 confirmações). Reportes falsos podem resultar em suspensão da conta.

4. Responsabilidades

O Movecity não se responsabiliza por decisões tomadas exclusivamente com base nas estimativas exibidas, dada a natureza colaborativa e piloto da plataforma.

1. Dados que coletamos

Coletamos e-mail, nome e dados de geolocalização (apenas quando o app está em uso) para exibir paradas e linhas próximas. A localização não é compartilhada com outros usuários.

2. Finalidade do tratamento

Os dados são tratados para prestação do serviço de mobilidade, geração de alertas de rotas preferidas e validação de reportes — sempre de forma anônima para terceiros.

3. Seus direitos (LGPD)

Você pode acessar, corrigir, exportar ou solicitar a exclusão dos seus dados a qualquer momento pelo perfil ou pelo e-mail privacidade@movecity.app.

4. Compartilhamento

Dados agregados e anonimizados podem ser disponibilizados a gestores públicos (SEMOB/GDF) para melhoria do transporte. Nenhum dado pessoal identificável é compartilhado.

Encarregado de Dados (DPO): Grupo Segurança no Transporte — UCB · privacidade@movecity.app
